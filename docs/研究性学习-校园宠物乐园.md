### （一）研究背景及意义

**1. 问题的提出**

班级积分（操行分）是许多学校日常管理的重要工具，但传统做法大多依赖纸质登记表或 Excel 表格，存在三个明显的痛点：

一是反馈不及时。加分、扣分之后，学生要等老师登记、汇总、公布，才能看到自己的分数变化，激励效果大打折扣；二是互动性不强。积分只是"一个数字"，学生只能被动接受，缺少参与感和趣味性；三是展示不直观、数据不安全。排行榜往往靠手动抄写张贴，统计费时，纸质表格和单机文件还容易丢失。

我们在课题开始前先查阅了 GitHub 上的同类开源项目（调研记录见附件《调研报告-校园宠物系统》），发现已有"班级积分系统"和"宠物养成系统"的开源方案，但普遍存在功能不全（没有商店、没有独立用户系统）或数据不能多设备共享（纯浏览器本地存储）的问题。综合以上情况，本课题决定基于现有开源项目的架构，自主开发一套同时包含"积分管理"和"宠物养成"的 Web 系统，解决上述痛点。

**2. 研究的价值与意义**

- 实用价值：让加减分即时生效、全程留痕、公开可查；把"扣分惩罚"变成"养宠物"的正面激励，提升班级管理的效率和趣味性。
- 技术价值：通过一个真实可运行的软件项目，学习并实践 Web 前后端开发、数据库设计、模块化编程、数据同步与安全防护等信息技术知识。
- 教育意义：探索信息技术与班级管理相结合的具体路径，也为学校一体机场景提供一个轻量、可离线运行的班级管理工具。

### （二）研究内容

本课题围绕一个可实际运行的软件系统展开，核心研究内容是从代码中提炼出的三个功能模块：

**模块一：积分管理模块。** 支持单点、快捷、批量三种方式对学生进行加/扣分，每次操作必须填写理由，并在数据库的流水表中记录"谁、何时、为什么、加扣多少"；支持自定义快捷理由；自动计算排行榜（同分同名次）。

**模块二：宠物养成与商店互动模块。** 提供 12 种宠物供学生选择领养，宠物拥有健康、饱食、心情、清洁四项属性，按规则自动切换"生病、生气、睡觉、开心"等状态；提供 12 种道具（食物、清洁用品、玩具、医疗、成长书）的商店与背包系统，宠物随积分兑换的经验值分 7 个阶段成长（蛋→破壳→幼年→……→传说）。

**模块三：界面交互与展示模块。** 设计学生、教师、管理三套界面，并实现用于班级一体机的大屏轮播模式（排行榜领奖台 + 全体宠物墙），界面采用毛玻璃风格并针对触屏操作做了优化。

此外，为保证系统真实可用，还完成了数据同步与备份功能（本地 SQLite 与云端双路同步、冲突由用户裁决、自动快照备份、软删除墓碑），以及登录限流、密码哈希等安全措施。

### （四）研究成果——文本材料

**标题：** 校园宠物乐园——基于 Web 的班级积分管理与宠物养成系统

**摘要（150 字以内）：**

> 针对班级积分管理中登记繁琐、反馈不及时、展示不直观的问题，本课题用 Vue 3、TypeScript、Node.js、Express 和 SQLite 开发了"校园宠物乐园"系统，实现积分加减与流水、宠物养成与商店、排行榜与大屏展示、数据同步与备份，并经过测试验证。试用表明，系统提升积分管理的效率与趣味性。

**关键词（不超过 5 个）：** 积分管理；宠物养成；Vue 3；Node.js；SQLite

**正文：**

**一、问题的提出**

班级积分管理是日常班级管理中的常见需求，但纸质登记和 Excel 汇总的方式存在反馈慢、不直观、易丢失等缺点。随着班级一体机的普及，班级里其实已经有了可以运行 Web 应用的显示设备，却缺少配套的轻量软件。本课题希望开发一套基于 Web 的班级积分管理与宠物养成系统，让积分管理更高效，让激励方式更有趣。

**二、系统总体设计**

系统采用前后端分离的架构：前端负责界面展示与交互，后端负责数据存取与业务逻辑，两者通过 HTTP 接口通信。前端使用 Vue 3 框架，配合 Vite 构建工具、TypeScript 类型检查和 Tailwind CSS 样式框架；后端使用 Node.js 运行环境、Express 框架和 Node 22 内建的 SQLite 数据库（单文件存储，拷贝即备份，非常适合一体机离线场景）。系统按角色分为学生、教师、管理三套界面，并单独提供大屏展示模式。数据表主要包括学生表、宠物表、宠物种类表、道具表、积分流水表、状态规则表等。

**三、核心功能实现**

1. 积分管理。加减分操作通过一个统一的函数完成：先校验分值必须为非零整数，再在数据库事务中原子地更新学生积分（"积分 = 积分 + 分值"），同时插入一条包含学生、分值、理由、操作者、时间的流水记录，保证并发操作不丢数据。教师端支持单选、多选和批量操作，快捷理由可自定义（最多保留 5 条）。
2. 宠物养成。每种宠物有健康、饱食、心情、清洁四项属性，属性值随时间变化；系统按"状态规则表"逐条匹配，自动得出当前状态（如饱食和心情都低时显示"睡觉"，健康低于阈值显示"生病"）。学生在商店用积分购买道具（食物、清洁、玩具、医疗、成长书），使用道具后对应属性变化，再联动状态更新，形成一个完整的反馈闭环。宠物经验达到阈值（100、300、600、1000、1500、2200）逐级成长，7 个阶段分别对应"蛋、破壳、幼年、成长、成熟、进化、传说"。
3. 排行榜与大屏展示。排行榜按积分降序排列并处理并列名次，前三名以领奖台形式突出展示；大屏模式自动轮播"排行榜"和"宠物墙"两个画面，适合放在班级一体机上持续展示。
4. 数据同步与安全。系统支持本地 SQLite 与 Supabase 云端之间的双路同步：同步前自动生成本地快照，先增量拉取、再增量推送，遇到同一行两边都改动的冲突时不静默覆盖，而是弹出双方最后更新时间由用户裁决；所有删除均为软删除（墓碑），可跨设备传播。此外，管理员密码使用 bcrypt 哈希存储，登录失败按 IP 限流（每分钟最多 10 次），头像上传限制图片类型与大小，防止常见安全风险。

**四、测试与运行效果**

开发过程中编写了 25 个单元测试用例，覆盖数据迁移、种子数据、宠物状态计算、积分事务、同步引擎的冲突检测与墓碑处理、快照备份等；另编写了 16 项端到端冒烟测试脚本，自动验证登录、学生管理、批量加减分、排行榜、购买与使用道具、两路同步等完整流程，测试全部通过。系统最终以"双击 start.bat 启动、浏览器访问"的方式部署到班级一体机运行，大屏模式配合触屏按钮使用正常。

**五、总结**

本课题完成了从需求分析、架构设计、编码实现到测试部署的完整软件开发流程，产出了一个真实可运行的班级积分管理与宠物养成系统，解决了反馈不及时、互动性不强、展示不直观的问题，达到了预期目标。

### （六）研究成果简介（成果鉴定表·附件二）

针对班级积分管理中登记繁琐、反馈不及时、展示不直观的问题，本课题利用 Vue 3、TypeScript、Tailwind CSS、Node.js、Express 与 SQLite 等技术，设计并实现了"校园宠物乐园"班级积分管理与宠物养成系统。系统提供学生、教师、管理三套界面，实现积分加减与流水记录、12 种宠物养成、道具商店、排行榜与大屏轮播、数据同步与备份等功能。经 25 个单元测试与 16 项端到端冒烟测试验证，并在班级一体机上实际运行试用，教师反馈操作简单、反馈即时，学生参与积极性明显提高，达到了预期目标。

### （七）研究反思

通过这次课题，我第一次完整走过了"调研→设计→开发→测试→部署"的软件生命周期，学会了使用 Vue 3、Node.js、SQLite 等技术开发一个真实项目，也体会到版本管理和自动化测试对保证代码质量的作用。

反思不足：一是时间安排偏紧，前期需求讨论不够充分，开发中反复修改界面；二是本组的实际分工不够均衡，大部分编码工作集中在一名同学身上，其他成员主要承担测试、记录和资料整理，这提醒我们小组合作要提前明确分工、定期同步进度；三是系统的数据统计和互动玩法还有提升空间，后续可以继续完善。
