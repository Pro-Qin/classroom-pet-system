## 一、结论速览

| 结论 | 说明 |
|------|------|
| **现成"积分+宠物养成"一体化的轮子就两个** | `classroom-pet-system`（纯前端零部署）和 `class-pet-garden`（星光班级宠物园，全栈） |
| **纯积分系统轮子很多**（6+ 个） | 德育量化、综合素质测评、班级积分抽奖等，但没有宠物玩法 |

| **最快见效路径** | 克隆 `classroom-pet-system`，一条命令跑起来看效果（10 分钟） |

## 二、重点轮子详情

### ⭐ 1. Aionara/classroom-pet-system —— 先试跑这个

- **链接**：https://github.com/Aionara/classroom-pet-system
- **Stars 28 / 活跃**（2026-08 仍在更新）/ **License: AGPL-3.0**（可商用改代码，部署网络服务须开源你的修改，个人项目无碍）
- **技术栈**：Vue 3（CDN 引入）+ CSS3 + localStorage，零构建、零依赖
- **运行**：`python -m http.server 8080` 即可，浏览器访问 localhost:8080
- **功能**（很全）：
  - 🥚 宠物孵化：新生学生选宠物、起名、孵化
  - 🐾 四维状态：生命/饱食/心情/清洁，随时间衰减
  - 🎮 道具商店：积分买食物/清洁/玩具/医疗
  - ✨ 成长升级：经验值升级自动换形象；长期不喂变回蛋，喂 3 次复活
  - 📋 任务系统：教师发布 → 学生提交 → 教师审核 → 得积分
  - ⭐ 积分系统：任务得分 + 教师手动发放/扣除，有明细
  - 🏆 排行榜：前三名领奖台特殊展示
  - 🎒 背包、👩‍🏫 教师端、🛡️ 管理员端、📱 响应式
- **注意**：README 说纯前端，但仓库里已出现 `api/*.php`（auth/admin/students/tasks），作者可能正在加后端，以实际代码为准。
- **缺点**：localStorage 单机存储 —— 一体机上的数据学生手机看不到，多人不同步。

### ⭐ 2. luomor-web/class-pet-garden（星光班级宠物园）—— 正式选型基底

- **链接**：https://github.com/luomor-web/class-pet-garden ｜ 在线演示：https://8.147.56.12/
- **Stars 5 / License: 无**（⚠️ 代码默认"保留所有权利"，不能直接抄代码；但素材是作者自己 AI 生成的，画风 prompt 在文档里公开，可自行复刻）
- **技术栈**：
  - 前端：Vue 3 + TypeScript + Tailwind CSS + Vite
  - 后端：Node.js + Express + better-sqlite3（SQLite 单文件数据库，零配置）
  - 测试：63 个用例通过（Vitest）
- **功能**：
  - 🎓 多班级管理；📊 实时积分排行榜
  - 🐾 **24 种宠物 × 8 级成长** = 192 张宠物图（AI 生成扁平卡通风，压缩后约 14MB），Lv.8 为"传说（毕业）"称号
  - ⭐ **83 条评价规则**（学习/行为/健康/其他，加减分各若干）可自定义
  - 💾 SQLite 数据备份恢复；📥 Excel 批量导入学生；🔤 拼音匹配搜索
  - 📱 响应式；升级动画（useLevelUp）
- **部署**：Nginx 托管静态文件 + 后端独立运行；提供 Dockerfile；systemd 服务文档
- **缺点**：README 提到商店系统、用户系统"后续会加"—— 还没做，这正是你要补的部分。

## 三、技术选型建议

### 推荐方案：Vue 3 + Vite + TypeScript + Tailwind CSS ／ Node.js + Express + better-sqlite3

即复刻 `class-pet-garden` 的架构。理由：

1. **一体机友好**：SQLite 单文件、零配置，不需要装数据库服务；后端 + 构建产物拷到一体机，一个 `start.bat` 启动，局域网浏览器访问。
2. **学生多设备共享数据**：服务端存储，一体机 / 学生手机 / 平板数据实时同步（classroom-pet-system 的 localStorage 做不到）。
3. **开发速度**：对标现成架构（63 个测试的质量基线），不用从零设计。
4. **素材方案现成**：class-pet-garden 公开了 FLUX 画风 prompt（"kawaii chibi, flat cartoon, big round sparkling eyes, children book illustration"），用同一套 prompt 自己生成宠物图，既避开无 license 的代码/素材问题，又能定制专属宠物。
5. **UI 动画精美且跑得动**：Tailwind + CSS 关键帧（浮动/弹跳/升级闪光）+ GSAP 或 Motion One 做过渡；192 张 PNG 帧切换动画在一体机上性能无压力（避免 Live2D/3D 等重型方案）。
6. **离线部署**：构建产物全本地化，不依赖 CDN —— 学校网络常封锁外网，这点很关键。

### 一体机部署拓扑

```
[一体机/教师机]  Node 服务(:3000) + 静态前端 + SQLite(lumo.db)
        │ 局域网 http://一体机IP:3000
        ├─ 学生手机/平板浏览器
        └─ 大屏展示模式（排行榜 + 宠物墙，触屏大按钮）
```

- 备份：拷贝 `*.db` 文件即可，或导出 Excel。
- 升级：开发机构建好，替换静态目录 + 重启服务。

### 需要补的功能（相对现成轮子）

| 功能 | 来源 |
|------|------|
| 商店/道具系统 | classroom-pet-system 有，可借鉴设计；class-pet-garden 没做 |
| 独立用户系统（学号登录、密码） | 两个项目都弱，需自建（class-pet-garden 只有简易认证） |
| 大屏排行榜模式 | 一体机展示刚需，需自建 |
| 宠物互动（喂食/玩耍/清洁）| classroom-pet-system 的四维状态设计可借鉴 |

## 四、建议路线（如果开工）

1. **阶段 0**：clone `classroom-pet-system` 本地跑起来，确认玩法和交互你喜欢的样子（10 分钟）。
2. **阶段 1**：按本报告推荐架构搭骨架（Vue3 + Node + SQLite），实现登录 + 积分 + 排行榜 + 宠物领取/升级（对标 class-pet-garden 已完成部分）。
3. **阶段 2**：补商店系统、宠物互动（四维状态）、大屏模式。
4. **阶段 3**：用 FLUX prompt 生成/替换专属宠物素材，打磨动画。
