# 校园宠物乐园 · 产品官网 / 宣传片分镜（film v4）

**片长** 36.000 s · **30 fps** · **1080 帧**（快门 4× 采样时 4320 张）
**网格** 120 BPM → 1 拍 0.5 s / 1 小节 2.0 s → 18 小节。**每一屏正好 2 小节（4 s）**，九屏 = 36 s，所有转场都落在小节线上。
**形态** 这一版不是"九段幻灯片"，而是**一个能用的完整网页**：正常打开它就是产品官网，自己可以滚、可以点；
加 `?render` / `?t=` 才进入片子模式，由 `window.__seek(t)` 驱动，**小黄点代替鼠标指针**去点真实按钮。

```
浏览器直接打开 promo/site.html        → 官网（9 屏，自己滚、自己点）
promo/site.html?t=7.6                 → 定格第 7.6 秒
promo/site.html?render                → 停表，交给渲染器驱动
```

## 运动模糊怎么实现的

```bash
node render.mjs --frames --film site.html --w 960 --h 540 --workers 4 \
                --out out/sh --dur 36 --shutter 4
# out/sh/s000000.jpg … s004319.jpg  （1080 输出帧 × 4 采样）

ffmpeg -framerate 120 -i out/sh/s%06d.jpg \
       -vf "tmix=frames=4,fps=30,scale=in_range=full:out_range=tv,format=yuv420p" …
```

`tmix=frames=4` 把连续 4 张平均掉（60 Hz 采样、1/30 s 曝光），再 `fps=30` 每 4 张取 1 张 ——
等价于 180° 快门。**静态帧不浪费**：`window.__motion(t0,t1)` 给出两时刻之间画面上最大位移，
小于 2 px 的帧只截一张、其余三张直接复制（`fs.copyFileSync`）。

实测代价：不加快门 960×540 约 6 分钟；**2× 快门 31 分钟**（2160 张）；4× 快门 49 分钟（4320 张）。

### 交付的这一版用的是 2× 快门 —— 老实说清楚差别

- **2 采样**：快门窗口里只有两个时刻，平均出来是**双影**（两幅相隔约 22 px 的像）。
  在 30 fps 播放时读作"速度感/拖影"，但**暂停在过渡帧上能看出是双影**，不是连续拖影。
- **4 采样**：平均出来是真正的连续拖影（上一轮渲染过一版，联系表里看得很清楚），代价是全片 49 分钟。

要升级成 4 采样（更接近真实 180° 快门）：

```bash
node render.mjs --frames --film site.html --w 960 --h 540 --workers 4 --out out/sh --dur 36 --shutter 4
ffmpeg -framerate 120 -i out/sh/s%06d.jpg -i out/score.wav \
  -vf "tmix=frames=4,fps=30,scale=in_range=full:out_range=tv,format=yuv420p" …（其余参数同上）
```

试过的捷径（都不行，记下来免得再试）：用 `minterpolate=fps=120:mi_mode=blend` 从 60 fps 补到 120 fps
再 `tmix=4`，因为 blend 只是交叉淡入淡出，插出来的还是同一时刻的两幅图，**结果依然是双影**。
真正的多采样只能在渲染端多取几个 `t`。

**另一个坑**：一开始给每张 3D 卡加了 `filter:blur(40px)` 背光和 `blur(12px)` 投影，
每帧要重做 14 次大半径模糊，渲染慢到 5.6 s/帧；换成纯径向渐变后同一批帧降到 0.67 s/帧（**8 倍**）。

## 已知取舍

- **运动模糊只覆盖整帧**：`tmix` 平均的是整幅画面，所以静止的文字会跟着动态内容一起被轻微平均。
  快门 4 采样、曝光 1/30 s，静态元素在 4 个子采样里是同一像素，实际上不会被糊掉。
- **3D 是 CSS 透视，不是真三维**：卡片在 Z 轴上有分层（背光/投影/内容），但不是网格模型。
  好处是文字始终是矢量原生锐度。
- **演示数据是示意**：只有 6 个学生的名字与积分来自项目种子文件，其余为演示数据。
